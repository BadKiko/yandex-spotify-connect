# Yandex Spotify Connect

Автономный мост между Spotify Connect и Яндекс Станциями с поддержкой мультирума и веб-интерфейсом.

## Возможности

* Автоматический поиск Яндекс Станций в локальной сети (mDNS)
* Поднятие отдельного устройства Spotify Connect для каждой колонки
* Потоковая передача аудио по локальному протоколу Glagol
* Поддержка прошивок Яндекса 2026 года (HLS / audio_play)
* Веб-панель управления с возможностью включения и отключения устройств
* Полная автономность без необходимости в Home Assistant

## Быстрый старт

1. Склонируйте репозиторий
2. Скопируйте `config.example.yaml` в `config.yaml` и укажите ваш `yandex_music_token`
3. Запустите через Docker Compose:

```bash
docker compose up -d
```

Веб-интерфейс доступен по адресу `http://<IP_СЕРВЕРА>:8555`.
